# ♟️ شطرنج الكوتش العراقي (أبو جعفر) - Iraqi Chess Coach

تطبيق شطرنج تفاعلي بالكامل وممتع يعمل مباشرة داخل المتصفح (Zero Dependencies) بصيغة ملف HTML واحد متكامل.

## 🌟 المميزات
- **بدون أي مكتبات خارجية (Standalone HTML5):** لا يحتاج إلى سيرفر أو تثبيت حزم أو إنترنت للعمل.
- **رسومات قطع ستونتون دقيقة (High-Resolution Staunton SVGs):** قطع واضحة المعالم بألوان متباينة وتصميم عالمي.
- **المدرب العراقي (أبو جعفر):** تفاعل صوتي وكتابي ذكي باللهجة العراقية الشعبية مع كل نقلة وموقف (بداية اللعب، التكتيكات، البلاندرز، الكش مات).
- **أصوات تفاعلية خاصة:**
  - **الملك الأبيض:** تعليق وصوت خاص عند كل حركة («ابو طيز كبير»).
  - **الوزير الأبيض:** صوت وتعليق («اوياه»).
  - **قلعة الأبيض:** تعليق عند أول حركة («هاي لخالتك صارلي نص ساعة منتظرك»).
  - **بيادق الأبيض:** صوت («آه»).
  - **أصوات الرقعة:** محاكاة أصوات النقل الخشبي والأكل والكش بتقنية `Web Audio API`.
- **محرك شطرنج وذكاء اصطناعي (AI):** مستويات صعوبة متعددة (سهل، متوسط، صعب) مع قواعد التحريك والترقية والتراجع.

## 🚀 طريقة التشغيل على GitHub Pages
1. انسخ محتويات مستودع GitHub هذا.
2. اذهب إلى **Settings** > **Pages** في مستودعك.
3. اختر تشغيل الموقع من الفرع الرئيسي (`main` أو `master`).
4. سيصبح موقعك متاحاً ويعمل أونلاين فوراً عبر رابط GitHub Pages مجاناً!
